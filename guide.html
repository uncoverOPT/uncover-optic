GitHub에서 직접 파일 수정하기

🖥️ GitHub란?

홈페이지 파일들이 저장되어 있는 온라인 보관소입니다. 컴퓨터에 아무것도 설치하지 않아도 웹 브라우저에서 직접 텍스트를 수정하고 저장할 수 있습니다.

🚀 텍스트 수정 전체 과정 (5단계)

1
GitHub 접속 브라우저에서 github.com/uncoverOPT/uncover-optic 로 이동합니다.
2
파일 선택 수정하고 싶은 파일(예: index.html)을 클릭합니다.
3
편집 모드 열기 파일 내용 우측 상단의 ✏️ 연필 아이콘을 클릭합니다.
4
텍스트 찾아서 수정 Ctrl+F (Mac은 ⌘+F)로 바꾸고 싶은 단어를 검색해서 찾은 뒤 수정합니다.
5
저장 (Commit) 화면 우측 상단 초록 버튼 "Commit changes"를 클릭 → 팝업에서 다시 초록 버튼 클릭. 1~2분 후 사이트에 반영됩니다.
✅ 확인 방법
저장 후 1~2분 기다렸다가 uncoveroptic.kr 에서 F5 (새로고침)하면 변경사항이 반영됩니다.

이미지 교체 방법

📸 이미지 교체 2가지 방법

방법 A · 같은 이름으로 교체 (추천 ✅)

새 이미지를 기존 파일과 같은 파일명으로 저장한 뒤, GitHub에 업로드해서 덮어쓰는 방식입니다. HTML 파일을 건드릴 필요가 없어 가장 안전합니다.

1
새 이미지 파일명을 기존과 동일하게 저장 예: 피팅 사진을 교체하려면 새 파일을 fitting_work.jpg 로 저장
2
GitHub → images 폴더 클릭 저장소에서 images 폴더로 이동
3
"Add file" → "Upload files" 클릭 새 이미지 파일을 업로드 → 같은 이름이면 자동으로 덮어쓰여짐
4
"Commit changes" 클릭하여 저장 1~2분 후 사이트에서 새 이미지가 보입니다
방법 B · 새 파일명으로 추가

새 파일명으로 업로드한 뒤, HTML에서 파일명을 변경하는 방식입니다.

1
images 폴더에 새 이미지 업로드 예: new_staff.jpg
2
해당 HTML 파일에서 기존 파일명을 새 파일명으로 변경 src="images/old_staff.jpg" → src="images/new_staff.jpg"
💡 이미지 파일명 규칙
파일명은 반드시 영문 소문자 + 숫자 + 언더바(_)만 사용하세요.
✅ 올바른 예: staff_photo.jpg, event_2026.jpg
❌ 잘못된 예: 직원 사진.jpg, Staff Photo.jpg (한글, 공백 금지)

🚫 수정 금지 항목

항목 이유
style.css 파일 전체 디자인 전체를 제어. 잘못 수정하면 레이아웃이 무너짐
<head> 안의 <meta>, <link> 태그 SEO, 검색엔진 연결 정보. 수정 시 검색 노출에 영향
<script> 태그 내부 JavaScript 기능 코드. 오타 하나로 기능 전체가 망가질 수 있음
class="..." 속성 값 CSS 스타일과 연결된 이름. 변경 시 디자인 깨짐
href="..." 링크 주소 (의도하지 않은 변경) 잘못된 링크로 연결되거나 페이지 이동이 안 됨
naver-site-verification 메타 태그 네이버 서치 어드바이저 인증. 삭제 시 검색 등록 해제

🆘 문제별 해결 방법

증상 원인 해결법
저장했는데 변경이 안 보임 브라우저 캐시 Ctrl+Shift+R (Mac: ⌘+Shift+R) 로 강제 새로고침. 또는 1~2분 더 기다리기
이미지가 안 보임 (깨진 아이콘) 파일명 오타 또는 대소문자 불일치 HTML의 src="images/파일명.jpg"과 실제 업로드된 파일명이 정확히 일치하는지 확인
페이지 레이아웃이 깨짐 태그를 잘못 지웠거나 style.css 수정 GitHub에서 해당 파일 → History → 이전 버전으로 Revert (되돌리기)
팝업이 뜨지 않음 "오늘 하루 보지 않기" 클릭 후 캐시 남음 브라우저 시크릿 창(Chrome: Ctrl+Shift+N)에서 접속해보기
GitHub에서 저장이 안 됨 로그인 세션 만료 GitHub에 다시 로그인 후 재시도
🆘 페이지가 완전히 망가졌을 때
GitHub → 해당 파일 클릭 → "History" 버튼 → 정상이었던 시점의 커밋 클릭 → 우측 "<>" 버튼 → 파일 내용 확인 → 다시 최신 파일로 돌아와서 잘못된 부분만 찾아서 수정. 또는 AI 개발자에게 연락하세요.
